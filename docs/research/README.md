Historical records preserve what was claimed at the time. They are not automatically
current, independently replicated, or eligible for capital use. The current audit
identifies retired strategies and contradictory metric labels; retain those failures.

For new work, use a dated report with source identities and a linked public issue.
Use the existing lifecycle schema for strategies and add public-safe evidence under
`docs/evidence/`. Do not move old records merely to make the tree look cleaner.
