The root README is the entry point, not a second source of model results. Dated
reports retain their original context. Read the current audit before treating an
older document's "validated", "proven" or return-target wording as established fact.

Evidence precedence depends on the question: source bytes and versioned runs for
numeric results; the approved frozen specification for experiment definitions;
explicit human decisions for promotion. Newer narrative prose does not silently
supersede conflicting primary records. Record and resolve discrepancies.
