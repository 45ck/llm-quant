# Existing experiment workspace

[Repository map](../docs/repository-map.md) · [Research catalogue](../docs/research/README.md)

This existing directory contains [manifest.json](manifest.json), [prompts](prompts/)
and [results](results/). Their paths and content are retained. The manifest is an
existing research artifact, not a new endorsement of its historical conclusions.

Use `docs/research/` for reader-facing proposals, replications and dated analyses;
`docs/evidence/` for public-safe run evidence; and the existing `data/strategies/`
lifecycle schema for strategies. Do not create a competing strategy registry here.
Private and restricted inputs belong in ignored local storage, not this directory.
